## Режим «Только прокси»

В этом режиме OneDPI не открывает свой VPN. Он запускает обход как локальный прокси, а другое приложение пускает через него свой трафик.

1. В OneDPI: «Настройки» → «Режим работы» → **«Только прокси»**.
2. В AdGuard: «Настройки» → «Фильтрация» → «Сеть» → «Прокси» → добавить прокси **SOCKS5**, адрес `127.0.0.1`, порт `1081`, и включить его.
3. В AdGuard исключи OneDPI из маршрутизации трафика, иначе трафик пойдёт по кругу.
4. Включи OneDPI кнопкой на главном экране. Разрешение на VPN в этом режиме не нужно.

### HTTP-прокси

С версии 0.2.0 рядом с SOCKS5 работает и HTTP-прокси: адрес `127.0.0.1`, порт `1088`. Он нужен там, где SOCKS5 указать нельзя: в настройках прокси Wi‑Fi в Android («Прокси» → «Вручную») и в браузерах. Через него идут сайты по HTTPS. Обычные незашифрованные запросы по HTTP он не пропускает.

Прокси для Telegram в этом режиме тоже работает. Исключения приложений и свой DNS — нет: этим управляет приложение, которое держит VPN.

## Свой DNS

«Настройки» → «DNS в туннеле». Обычно менять не нужно.

- **Как в сети** — DNS провайдера или роутера, по умолчанию.
- **Cloudflare** или **Google** — если провайдер подменяет ответы DNS.
- **Comss** — открывает часть сервисов, закрытых для России (например, Gemini), через свои серверы. Это сторонний сервис: он видит, к каким сайтам ты обращаешься, а трафик к закрытым сервисам идёт через него. Включай, только если это тебе подходит.
