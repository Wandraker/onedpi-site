## Что он делает

Smart проверяет несколько способов обхода на твоей сети и выбирает тот, при котором открывается больше всего, а обычные сайты работают так же, как без OneDPI.

## Память по сетям

Результат запоминается отдельно для каждой сети: домашний Wi-Fi, рабочий, мобильный интернет. При следующем подключении к знакомой сети подбор не нужен.

Сети различаются по зашифрованному отпечатку, который хранится только на телефоне. Названия сетей и адреса никуда не уходят.

## Когда он подбирает заново

- Ты подключился к сети, которой ещё не было.
- Прошло больше суток с прошлого подбора.
- Ты нажал «Переобучить для этой сети» на вкладке диагностики.

## Если перестало открываться

Сначала нажми «Переобучить для этой сети». Это сбросит выбор только для текущей сети, остальные сети и настройки не затронет.
