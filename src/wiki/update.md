## Обновление в приложении

С версии 0.2.1 OneDPI сам проверяет, нет ли новой версии. О тебе при этом ничего не отправляется: приложение просто читает файл с этого сайта.

Когда выходит новая версия, появляется окно со списком изменений:

- **Обновить** — файл скачивается с прогрессом, проверяется по контрольной сумме, потом Android спрашивает, установить ли его;
- **Позже** — окно закроется до следующего запуска;
- **Пропустить** — эта версия больше не будет предлагаться. Важные обновления пропустить нельзя, только отложить.

Проверить вручную можно в «Настройки» → «О приложении» → «Проверить обновления».

После установки OneDPI сам подключится снова, если был включён, и заново подберёт способ для твоей сети. Нажимать «Переобучить» не нужно. Способ, который ты закрепил сам, останется.

## Разрешение на установку

Android ставит приложения не из магазина только с разрешения. Его спрашивают один раз, при первом обновлении из приложения:

1. В окне OneDPI нажми «Открыть настройки», откроется нужный экран.
2. Включи «Разрешить установку из этого источника» (на Xiaomi — «Доверять этому источнику», на старых Android — «Неизвестные источники»).
3. Вернись назад в OneDPI, установка продолжится сама.

Если Play Защита скажет, что приложение неизвестно, нажми «Подробнее» → «Всё равно установить». На Xiaomi система может сначала проверить файл, это обычная проверка.

## Вручную

Скачай новый APK на [главной странице](../) и установи поверх. Настройки сохранятся.

## «Приложение не установлено»

Так бывает, если новая версия подписана другим ключом. С alpha29 у OneDPI новый ключ подписи, поэтому alpha28 и более ранние версии не обновляются до неё поверх.

1. Удали старую версию OneDPI.
2. Установи новую.

Исключения приложений придётся выбрать заново. Smart подберёт способ сам при первом подключении.
